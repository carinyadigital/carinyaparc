not part of the durable documentation set: do not link them from `docs/`,
`AGENTS.md`, code, or comments. Intake, Gherkin AC, and assignment live
on GitHub issues. Issues may link here for design context.

```text
specs/{domain}/
└── design.local.md      # Technical design for open work
```
